# Readiness, the pre-announcement work

## Goal

Work through section 4 of the readiness review in its own order of value, so the repo
can be announced with a plugin trust story that is true, an updater that checks before
it unpacks, a release pipeline that is pinned, and a setup CLI that cannot lose a
user's originals.

## Context

The review's blockers (section 3) are closed in code as of v0.8.7, bar B4's GitHub
settings. Section 4 is six groups, none a blocker alone; the file and line references
are in the review and are not repeated here. Section 5 (residual risk) needs Mitch's
yes or no per line and is listed last.

## Approach

One slice per group, each its own commit with tests first where the code is testable
in-process, in the review's order: webview and plugin UI, self-update, release
pipeline, setup CLI, repository and licences, code health. Only the slice in flight is
`active`. Anything that changes what the webview may load is checked live in all four
windows before it merges.

## Steps

- [ ] **Webview and plugin UI.** Set a CSP (`script-src 'self' blob:`), then check
      icons, thumbnails and the four windows live; move consent-changing commands
      (`write_config`, `setup_run`, `hooks_install`, the installs) into a capability
      granted only to the settings window; restrict `script_action` Open to http(s) or
      non-executable paths; rewrite the trust paragraphs in PLUGINS.md and WIDGETS.md;
      record `csp` in DECISIONS.
- [ ] **Self-update.** Enforce `https://` and GitHub hosts on asset URLs; list the
      zip's entries for `..` and absolute paths, then extract into a fresh `0700` dir;
      tighten the codesign requirement to Developer ID; decide provenance out of band
      (`gh attestation` or minisign over `SHA256SUMS`) and record it.
- [ ] **Release pipeline.** Pin actions to SHAs in the job that holds
      `HOMEBREW_TAP_TOKEN`; stop interpolating repo variables into `run:`; give
      `install/install.sh` a `main()` wrapper and a pinned Homebrew installer; settle
      the AeroSpace dependency in `.github/cask/scuttler.rb` one way; add gitleaks and
      the audits to CI; make CI run `pnpm verify` once.
- [ ] **Setup CLI.** `sc_manifest_add/remove` must fail, not truncate, on an
      unreadable manifest; `remove` moves an edited generated file aside;
      `sc_touched_revert` checks for a pre-touch copy; `sc_write_atomic` follows a
      symlinked directory. (`sudoers status --mas --user` landed with B3.)
- [ ] **Repository and licences.** `SECURITY.md`, `CODEOWNERS`, a PR template;
      `THIRD-PARTY-LICENSES.md` generated by `cargo about` at release time; a `rev` on
      the `tauri-nspanel` dependency; `bug.yml` says not to paste `config.json` or the
      logbook.
- [ ] **Code health.** Record the lock-poisoning policy or add `lock_or_recover`;
      reasons on the four bare `#[allow]`s; SAFETY comments in `clipboard.rs`; mas ids
      must match `^[0-9]+$`; refuse `http://` for code installs; the Wi-Fi password off
      the `networksetup` argv; the two "no network" headers corrected; tests for the
      untested modules by risk (`commands.rs` first).
- [ ] **Section 5.** Mitch confirms or strikes each proposed residual risk; each
      accepted one becomes a DECISIONS or DEVIATIONS line.

## Acceptance criteria

- [ ] Each group above is either done or has a DECISIONS line saying why not.
- [ ] `pnpm verify` green after each slice; the CSP slice has its live checklist run.
- [ ] Memory: nothing here should be resident; if a slice adds anything, its
      `scripts/mem.sh --receipt` before and after goes in this file.

## Out of scope

A privileged helper (SMAppService) in place of the sudoers rule. Building releases in
CI instead of on the laptop (a decision to record, not work to do here). The thirteen
dev-tool majors (DEVIATIONS row 4, and Dependabot's pull requests).

## Risks / open questions

- A CSP can break a plugin's panel in ways only a live window shows.
- Moving commands behind a settings-only capability changes what a plugin panel can
  call; an existing plugin that relied on it breaks, and that is the point.
- Provenance out of band adds a key to keep; which key, and where, is Mitch's call.
