# 0.9 — light and dark themes, wallpaper, Focus mode wallpaper

## Goal

A light theme and a dark theme that swap with macOS, chosen visibly; a default wallpaper
that swaps with them; and a wallpaper per macOS Focus, like the iPad.

## Approach

See DECISIONS 2026-11-23 (0.9). Theme: Match System / Light / Dark, single by default,
schedule and Focus themes retired, seven new built-ins. Wallpaper: `lib/wallpaper.ts`
plans (Focus image → default light/dark image → theme backgrounds), `use-wallpaper.ts`
applies it from the panel window, `wallpaper.rs` sets it through NSWorkspace. Focus: an
opt-in that asks for Full Disk Access; Rust reports raw facts, TS evaluates schedules.
