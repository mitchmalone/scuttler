## Breaking changes

- **The name.** scuttlarr is now **scuttler**, at [www.scuttler.app](https://www.scuttler.app).
  The app is `scuttler.app`, the cask `mitchmalone/tap/scuttler`, the CLI `scuttler`, the
  config `~/.config/scuttler`, the state `~/.local/state/scuttler`, the built-in theme
  `scuttler`, the kit `@scuttler/tui`. Nothing else changed in this release: no feature,
  no default, no fix beyond the rename. The old domains redirect; the old cask points
  here and tells `brew` so.
- **What migrates by itself on first launch:** config, scripts, plugins, widgets, hooks,
  themes, triggers (and the generated `aerospace.toml` that touches them), the manifest, agents and awake state, usage mirrors, frecency history
  (the built-in rows included), the login item, custom shortcuts bound to the built-in
  rows, and the names inside `config.json` that were ours (`theme`, the light/dark pair,
  Focus mappings, a `themes.scuttlarr` override). The Claude Code hook entries in
  `~/.claude*/settings.json` are repointed the way a stale path always was. An install
  updated in place from 0.8.0 renames its own `/Applications/scuttlarr.app` folder and
  relaunches once. The bundle id stays `com.mitchmalone.scuttlarr`, so no permission you
  granted is asked for again.
- **Two one-time picks, because your own tools name the file:**
  - Claude Code: the theme installs as `scuttler`; pick `custom:scuttler` once (`/theme`).
  - The sleep rule for `awake`: run `scuttler sudoers on` once (one admin password). The
    old `/etc/sudoers.d/scuttlarr` keeps working until then, and that command removes it.
- **Shell files that import the theme.** If the Machine rung is on, `scuttler migrate`
  (which the app runs at launch) re-renders your `.zshrc`, Ghostty, tmux and git configs
  against the new state path and retires `~/.config/git/scuttlarr.gitconfig`. Until it
  has, `~/.local/state/scuttlarr` is a symlink to the new dir, so every terminal stays
  themed; the link goes once nothing we wrote names the old path. Dotfiles of your own
  that import `~/.local/state/scuttlarr/current/theme/` keep working through the link for
  this release; update them at your leisure.
- **Plugins** that import `@scuttlarr/tui` keep building: the old name maps to the same
  kit for this release. `@launcharr/tui`, two names back, no longer does.

## Highlights

**Workspace switches show at once.** AeroSpace's hook now writes the new workspace's
name into `~/.config/scuttler/triggers/workspace`, and the bar shows that name straight
from memory before anything is spawned or asked; the full snapshot follows. The 1 Hz
poll is a fallback again, not the path. Along the way the rename's one regression was
found and fixed: the generated `aerospace.toml` still touched the old `scuttlarr`
trigger path, so every switch waited for the poll (up to a second). A managed file is
repointed and its hook upgraded on first launch; a hand-written `aerospace.toml` keeps
working with a bare `touch`, it just waits for the snapshot.

**The bar costs less to run.** One thread feeds it: every source of change pokes one
channel, bursts become one snapshot, and two updates can no longer land out of order.
A snapshot that did not change is not sent again, and the front app comes from
AppKit instead of two processes a second. The agents' spinners now animate in the
compositor instead of repainting the strip sixty times a second. `scripts/mem.sh
--webkit` shows the part of the app's footprint macOS keeps in WebKit's helper
processes, which the receipt below does not count.

**Agent cells stop lying after Claude's recap.** Claude Code's "recap while you were
away" runs as a subagent three minutes after a turn ends, and its SubagentStop re-marked
a finished cell "working" for good (four cells, a day). A subagent event now never
changes a known session's state. The lasting fix, reading state from the pane's screen
the way herdr does, is planned for the next release (DECISIONS 2026-11-06).

**One name.** It is shorter to say and to type, and it is the last one. Everything that
was true of scuttlarr is true of scuttler; the docs were swept to the current state of the
app the day before the rename so that every sentence that carries the new name was already
true under the old one.

| ------------------------------ | -------- | ---------------------------------------------------- |
| Hotkey → panel visible         | < 100 ms | 0.32 ms at v0.8.0; path untouched, not re-measured   |
| Cold start → hotkey registered | < 1 s    | 179 ms                                               |
| Idle memory (the receipt)      | < 120 MB | 113.5 MB                                             |
| Workspace switch → bar repaint | —        | ~110 ms incl. a 60 ms capture; was 0.6–1 s           |
| Bar WebContent paint frames    | —        | 0 per 5 s sample at idle with agents working; was 53 |

Receipt: `scripts/mem.sh --receipt` on this build (`52ce9f1`, release profile, `tauri
build --bundles app`), the primary Mac (Mac17,6, 128 GB, one display, macOS 27.2), run
under a fresh profile, which is the reference config (bar on, agents monitor off, no
plugin services, Desktop rung off), 2026-11-06: three readings 10 s apart from a minute
after launch, 129.2 / 113.5 / 113.5 MB, median 113.5 MB (v0.8.0 read 113.1 MB). The
script warned of two child processes at the sampling instant; under a fresh profile the
bar asks `aerospace` once a second, so those were that call, not a resident helper.
Cold start is the same launch's own report. The summon path has no change in this
release; the hotkey → panel number is v0.8.0's and was not re-measured (the agent that
released cannot press keys). Daily footprint (unbudgeted, trend), same Mac, Mitch's
config (monitor on, borders, two plugin services, lights helper): 123 MB app, 386 MB with
helpers, 1 min after launch; v0.8.0 read 141 MB app, 483 MB with helpers, after 4 h 47
min. The rename adds no process; the bar's one push stream is what the app number lost.

## Install

```sh
brew install --cask mitchmalone/tap/scuttler
```

Upgrading with Homebrew: `brew upgrade` reports `scuttlarr` as deprecated in favour of
`scuttler`; `brew install --cask mitchmalone/tap/scuttler` over the top migrates the same
way the in-app update does. Or grab the dmg / zip below, or build from source (README).
