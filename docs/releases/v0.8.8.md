## Highlights

**Leave an app without a border.** `desktop.borders.exclude` in `config.json` is a list
of process names JankyBorders skips, for an app that draws to the edge of the display
and should not wear a frame, such as a game in borderless fullscreen:

```json
{ "desktop": { "borders": { "exclude": ["World of Warcraft"] } } }
```

The name is what `ps -c` shows, not the bundle id. A name containing a comma cannot be
listed (JankyBorders splits its list on commas and has no escape) and is dropped. Empty
by default; there is no Settings control yet, the key is edited by hand.

**Release tooling.** `scripts/release.sh` clears the bundle's dmg directory before it
builds and ships only `scuttler_<version>_*.dmg`. A by-hand `tauri bundle` leaves an
unsigned image there and the script used to take the first one it found. No shipped
release was affected.

**Homebrew is behind.** v0.8.7 never reached the tap: the job that writes the cask was
refused at push (a dead token), so `brew upgrade` still offers 0.8.6, and will until
the token is replaced. The app's own `updates ⏎`, the dmg and the zip are current.

**Still not run by a person.** The two paths v0.8.7 named have still not had their
hands-on run: the admin dialog end to end (install, remove, cancel) and the bar against
a real fullscreen game. The fallbacks are unchanged: `scuttler sudoers on` in a
terminal, and Settings → Menubar → Layout → "Hide the bar over fullscreen apps".

## Performance receipts

| Metric                         | Budget   | This release                                       |
| ------------------------------ | -------- | -------------------------------------------------- |
| Hotkey → panel visible         | < 100 ms | 0.32 ms at v0.8.0; path untouched, not re-measured |
| Cold start → hotkey registered | < 1 s    | 223 ms                                             |
| Idle memory (the receipt)      | < 120 MB | 114.4 MB                                           |

Receipt: `scripts/mem.sh --receipt` on this build (`a52e36e`, release profile, `tauri
build --bundles app`), the primary Mac (Mac17,6, 128 GB, one display, macOS 27.2.1), run
under a fresh profile, which is the reference config (bar on, agents monitor off, no
plugin services, Desktop rung off), 2026-11-19. Four launches. A fresh profile's first
launch runs the one-off icon extraction (`--extract-icons`, a child process that exits
within about a minute) and the bar's wifi cell runs `system_profiler` for a second now
and then; `mem.sh` counts children, so a reading that catches either is not the idle
number. The five readings with no child running: 123.7, 115.5, 110.0, 109.9 MB and, on
the fourth launch, 114.4 MB held flat from 20 s to 2 min; median 114.4 MB (v0.8.7 read
113.5 MB). Cold start 234, 218 and 223 ms, median 223 ms, and 208 ms on the fourth.
Nothing in this release is resident: the exclude list is one more argument to a
JankyBorders process that already runs, and only when borders are on. The summon path
has no change; the hotkey → panel number is v0.8.0's.
