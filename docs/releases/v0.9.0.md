<!-- v0.9.0 — a new settings window, light and dark themes, widget services, agents by session, a network cell -->

## Breaking changes

- **`github-actions.ts` and `vercel.ts` are gone from the bundled widgets; `jobs.ts`
  replaces both.** Once `jobs.ts` is in `~/.config/scuttler/widgets/`, the first launch
  moves their bar slot to one Jobs cell and turns them into Jobs services (pinned repos
  carried over). Installed copies of the old files are left alone; Settings → Widgets
  says they were replaced and offers removal. Bundled widgets are copied by hand, as
  before.
- **arr's settings moved into services** (Radarr, Sonarr, Prowlarr, Bazarr). The first
  launch with the new `arr.ts` moves the URLs, and each API key is copied forward from
  its old Keychain item on first use. Nothing is deleted.
- **The agents hover card is per session now, not per agent.** Hovering any agent box
  opens one card for that tmux session or herdr workspace.

## Highlights

**A new settings window.** A grouped sidebar with search, one layout grammar for every
page, and room for many more pages than the old tab strip had.

**Light and dark.** The Theme page has Match System, Light and Dark, with seven light
themes. **Wallpaper** swaps a light and a dark image with the theme; **Focus mode
wallpaper** (off by default; turning it on asks for Full Disk Access, because macOS keeps
the Focus database behind it) gives each Focus its own picture.

**Widgets get services and a configure screen.** Every widget opens its own screen from
Settings → Widgets. A widget can declare kinds of service; you add as many as you like
(two Dagu servers, say) from an **add service** dropdown, each with its own fields and
Keychain secrets. **Jobs** is the first: GitHub Actions (every active workflow, failing
first), Dagu and Vercel builds, one section per service, under one `activity` cell.

**Agents, by session.** Hover an agent box on the bar and one card shows the whole
session as tiles: needs-you tiles are filled, working ones outlined, unread done ones
striped, idle ones dim. Each tile has the session's name, what it is doing, how long the
state has held and, for Claude Code, how full its context is (amber at 60 %, red at 80 %).
Claude Code's own session files and transcript now back up the screen reading: a redraw
no longer flips a working cell, and Esc mid-turn settles to done within about 30 s.

**The Wi-Fi cell is a network cell.** On Ethernet, a tethered phone or a VPN it says
connected, with its own glyph and the adapter's name; only no connection at all reads
Offline.

**Also:** the Uptime widget reads an Uptime Kuma status page; the arr widget shows what's
new, coming and in flight; Homebrew's broken links are found and removed only when asked;
widget cards get a refresh button, sections, progress and badges; every AeroSpace call
has a 3 s deadline; "allow admin" copies the real `mas` binary.

**Homebrew is behind.** The tap's token is still dead, so `brew upgrade` offers 0.8.6
until it is replaced. `updates ⏎`, the dmg and the zip are current.

**Still to be run by a person:** the admin dialog end to end, the bar over a real
fullscreen game, Esc mid-turn on an agent, and adding a Dagu service with a real key.

## Performance receipts

| Metric                         | Budget   | This release                                       |
| ------------------------------ | -------- | -------------------------------------------------- |
| Hotkey → panel visible         | < 100 ms | 0.32 ms at v0.8.0; path untouched, not re-measured |
| Cold start → hotkey registered | < 1 s    | 201 ms                                             |
| Idle memory (the receipt)      | < 120 MB | 118.7 MB                                           |

Receipt: `scripts/mem.sh --receipt` on this build (`5f6a27e`, release profile, `tauri
build --bundles app`), the primary Mac (Mac17,6, one display), run under a fresh
profile, which is the reference config (bar on, agents monitor off, no plugin services,
Desktop rung off), 2026-11-28. Four launches, a minute after each: 126.9 MB (the
profile's first launch, with the one-off icon extraction), 124.7, 112.7 and 111.9 MB;
median 118.7 MB. The two later launches settle at about 112 MB (v0.8.8 read 114.4 MB).
Cold start 236, 197 and 201 ms, median 201 ms; one launch read 10.2 s, taken right after
two crashed test launches while macOS showed its crash-recovery dialog, and is left out.
Nothing new is resident under the reference config: services ride the existing widget
ticks, and the Claude session reader runs on the agents tick, which is off there.
