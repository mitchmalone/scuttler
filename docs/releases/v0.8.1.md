## Breaking changes

- **The name.** scuttlarr is now **scuttler**, at [www.scuttler.app](https://www.scuttler.app).
  The app is `scuttler.app`, the cask `mitchmalone/tap/scuttler`, the CLI `scuttler`, the
  config `~/.config/scuttler`, the state `~/.local/state/scuttler`, the built-in theme
  `scuttler`, the kit `@scuttler/tui`. Nothing else changed in this release: no feature,
  no default, no fix beyond the rename. The old domains redirect; the old cask points
  here and tells `brew` so.
- **What migrates by itself on first launch:** config, scripts, plugins, widgets, hooks,
  themes, triggers, the manifest, agents and awake state, usage mirrors, frecency history
  (the built-in rows included), the login item, custom shortcuts bound to the built-in
  rows, and the names inside `config.json` that were ours (`theme`, the light/dark pair,
  Focus mappings, a `themes.scuttlarr` override). The Claude Code hook entries in
  `~/.claude*/settings.json` are repointed the way a stale path always was. An install
  updated in place from 0.8.0 renames its own `/Applications/scuttlarr.app` folder and
  relaunches once. The bundle id stays `com.mitchmalone.scuttlarr`, so no permission you
  granted is asked for again.
- **Two one-time picks, because your own tools name the file:**
  - Claude Code: the theme installs as `scuttler`; pick `custom:scuttler` once (`/theme`).
  - The sleep rule for `awake`: run `scuttler sudoers on` once (one admin password). The
    old `/etc/sudoers.d/scuttlarr` keeps working until then, and that command removes it.
- **Shell files that import the theme.** If the Machine rung is on, `scuttler migrate`
  (which the app runs at launch) re-renders your `.zshrc`, Ghostty, tmux and git configs
  against the new state path and retires `~/.config/git/scuttlarr.gitconfig`. Until it
  has, `~/.local/state/scuttlarr` is a symlink to the new dir, so every terminal stays
  themed; the link goes once nothing we wrote names the old path. Dotfiles of your own
  that import `~/.local/state/scuttlarr/current/theme/` keep working through the link for
  this release; update them at your leisure.
- **Plugins** that import `@scuttlarr/tui` keep building: the old name maps to the same
  kit for this release. `@launcharr/tui`, two names back, no longer does.

## Highlights

**One name.** It is shorter to say and to type, and it is the last one. Everything that
was true of scuttlarr is true of scuttler; the docs were swept to the current state of the
app the day before the rename so that every sentence that carries the new name was already
true under the old one.

## Install

```sh
brew install --cask mitchmalone/tap/scuttler
```

Upgrading with Homebrew: `brew upgrade` reports `scuttlarr` as deprecated in favour of
`scuttler`; `brew install --cask mitchmalone/tap/scuttler` over the top migrates the same
way the in-app update does. Or grab the dmg / zip below, or build from source (README).
